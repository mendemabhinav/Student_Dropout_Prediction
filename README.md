# Student Dropout Prediction System 🎓

An end-to-end Machine Learning web application designed to predict student dropout risk early using academic, socio-economic, and behavioral metrics.

## 🚀 Tech Stack
- **Machine Learning:** Decision Tree Classifier (`scikit-learn`, `joblib`, `numpy`)
- **Backend:** Flask (`python`), `flask-cors`
- **Frontend:** HTML5, Tailwind CSS, JavaScript (ES6+), Font Awesome, Chart.js

## 📊 Dataset & Performance
- **Dataset:** Kaggle Student Attrition Dataset (10,000 Records)
- **Train/Test Split:** 80% Train (8,000 records) / 20% Test (2,000 records)
- **Model Accuracy:** 79.2%
- **Top Feature Driver:** `Attendance_Rate` (~32% Gini Importance)
